# On the number and sizes of coalescence classes in finite Markov chains

This repository contains a working note on some questions raised in

G. R. Grimmett and M. Holmes, *Coalescence in Markov chains*,  
*Journal of Theoretical Probability* **39** (2026), article 49.  
[doi:10.1007/s10959-026-01500-w](https://doi.org/10.1007/s10959-026-01500-w).  
Preprint: [arXiv:2510.13572](https://arxiv.org/abs/2510.13572).

The paper constructs an iid random map grand coupling of a strictly positive six-state transition matrix for which the eventual cardinality profile is (2, 4) or (3, 3) each with probability 1/2, giving a negative answer to Open Problem 3.11. Six states are shown to be minimal among finite irreducible chains with such couplings. This construction is extended to bipartite graphs, and a second counterexample is obtained by splitting states in an earlier example of Grimmett and Holmes.

The classical equal stationary mass theorem, for which a self-contained proof is furnished, also yields an affirmative answer to Open Problem 3.8: for Lebesgue-almost every strictly positive transition matrix, every consistent iid random map grand coupling has a single eventual coalescence class almost surely. For transition matrices with identical rows, the possible numbers of classes are characterized by partitions of equal stationary mass. In particular, for the uniform transition matrix on n states, these numbers are exactly the divisors of n, answering the question posed in Section 6 of Grimmett and Holmes.

This is a working draft and remains subject to revision.
