# Counterexample concerning Grimmett & Holmes (2026), Open Problem 3.11

This repository contains a preliminary note concerning Open Problem 3.11
in 

G. R. Grimmett and M. Holmes, *Coalescence in Markov chains*,  
*Journal of Theoretical Probability* **39** (2026), article 49.  
[doi:10.1007/s10959-026-01500-w](https://doi.org/10.1007/s10959-026-01500-w).  
Preprint: [arXiv:2510.13572](https://arxiv.org/abs/2510.13572).

This note constructs a counterexample using an i.i.d. random map grand coupling of a strictly positive six-state transition matrix for which the eventual coalescence classes have cardinalities (2,4) or (3,3), each with probability 1/2, yielding a negative result. This is a preliminary note and may be revised
or withdrawn.
